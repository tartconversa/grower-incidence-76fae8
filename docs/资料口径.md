# 资料口径

全部主体和观测均为本地合成资料，不代表企业、个人或真实设备。编号只在资料包内有意义，金额为人民币元，时刻统一为带 +08:00 的北京时间。空单元表示未知或不适用，不等于零；真假值用 true/false；数值不含千位分隔。CSV 行顺序不表示业务先后。时间区间采用左闭右开，除非字段说明另有规定。

households 仅为匿名经营主体，地块角色 owner/operator/payee 分别为所有、经营、代收。权利与合同生效区间为左闭右开；end 为空表示未结束。payments 的 kind=cash/accrued/fee 分别是现金收入、应收权益、费用，fee 金额为正并由 payer 承担；合作社代收并不等于其成员已收到。allocation 中 fixed/share/deduct_first 分别表示固定租金、比例分成及先扣费用，合同存在优先级，优先级小者先执行；这只是输入合同，不规定内部实现。coverage 的到场日不等于资料可知日。加工商联系为外溢途径而非已知因果结论。
rights 的 operator_end 为终止旧 operator 的补充事实，start 为实际终止日，available_at 之前仍按当时可知归属解释；它不是新经营人。contracts.kind=share 的 value 是扣除固定优先项后余款比例，未分配部分归经营人；fixed 为所有人月租。payments.cash 是销售对合作社的到账，household_receipts 才是给户现金；两者为同一资金链不同阶段，不能相加当收入。accrued 与 cash 为同销售总额的未付与已付部分，并非独立产出。销售活动放弃的 products 收益为原用途比较的一部分，费用按 payer 归属。month 是自资料基准起每30日一个结算期而非自然月。
fixed_per_mu 按当月生效地块亩数乘以 value 支付元每亩租金，优先于经营人余款。P004 跨村转包给 H065，H004 保留所有权与地租，原销售分成在转包生效日结束；成本由实际承担人计入，权利补报之前不能把未来转包当已知。labor 的 amount 是付给 worker 的劳动收入也是 payer 的成本，同一主体自付仅为劳动机会成本解释，不可造成额外现金流。

## households
匿名主体及预先登记的分组。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| household_id | string | 主体 |
| village | string | 村 |
| vulnerable | boolean | 困难经营户 |
| member_coop | string | 所属合作社 |

记录键：household_id。

## plots
地块条件与历史用途。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| plot_id | string | 地块 |
| village | string | 村 |
| area_mu | number | 亩 |
| slope_pct | number | 坡度百分比 |
| road_km | number | 运距 |
| prior_use | string | 原用途 |

记录键：plot_id。

## rights
经营权与代收随时间变化。更正进入后按其可知时点解释。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| right_id | string | 记录 |
| plot_id | string | 地块 |
| household_id | string | 主体 |
| role | string | 权利角色 |
| start | date | 生效 |
| end | date | 失效 |
| available_at | datetime | 可知时刻 |

记录键：right_id。

## contracts
真实支付规则，fixed 的 value 单位为元每月，share 为销售比例，deduct_first 为先扣项目。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| contract_id | string | 合同 |
| plot_id | string | 地块 |
| beneficiary | string | 受益主体 |
| kind | string | 分配方式 |
| value | number | 金额或比例 |
| priority | integer | 优先级 |
| start | date | 开始 |
| end | date | 结束 |

记录键：contract_id。

## payments
销售代收、应收和费用均为独立经济记录。fee 可由补单更正，不使用负数隐式抵销。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| payment_id | string | 支付 |
| month | integer | 月份索引 |
| plot_id | string | 地块 |
| recipient | string | 收款方 |
| payer | string | 费用承担人 |
| kind | string | 现金应收费用 |
| amount | number | 金额 |
| activity | string | 用途 |
| available_at | datetime | 可知时刻 |

记录键：payment_id。
